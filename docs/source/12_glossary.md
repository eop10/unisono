# 12. Глоссарий

A4 (ля первой октавы)
: Нота, от которой настраиваются все остальные. Её частота — «опорная»: 440 Гц в концертном строе,
  442 Гц в оркестровой практике, 415 Гц в барочной музыке.

Цент
: Сотая доля полутона, логарифмическая единица высоты. 1200 центов = октава.
  Отклонение в 10 центов уже слышно, ±3 цента считаются «строем».

Основной тон (f0)
: Частота колебания струны как целого. Именно её измеряет тюнер; обертоны кратны ей.

Обертон / гармоника
: Составляющая сигнала с частотой, кратной основному тону. У гитары обертоны часто громче
  основного тона — поэтому прямой поиск максимума спектра не работает.

NSDF (normalized square difference function)
: Нормированная автокорреляционная функция; её максимум на истинном периоде близок к 1.
  Основа метода McLeod.

MPM (McLeod Pitch Method)
: Метод определения высоты тона по NSDF с выбором первого пика выше порога `κ · max`.
  Устойчив к тембру и пропаданию основного тона.

Clarity
: Значение NSDF в выбранном максимуме; мера периодичности кадра. Порог 0,60 отделяет
  «ноту» от шума и речи.

YIN
: Альтернативный автокорреляционный алгоритм (кумулятивная средняя нормированная разность).
  По качеству близок к MPM.

Karplus–Strong
: Простой физический синтез щипковой струны; используется для генерации реалистичных
  тестовых сигналов с известной частотой.

dBFS
: Уровень сигнала в децибелах относительно полной шкалы: `20 · log10(rms)`. −50 dBFS — тихий
  сигнал, близкий к порогу гейта.

Окно анализа / hop
: `N` — число отсчётов, по которым считается высота тона; `hop` — сдвиг между соседними кадрами.
  При 48 кГц: `N = 4096` (85 мс), `hop = 1024` (21 мс).

PCM
: Импульсно-кодовая модуляция, «сырой» цифровой звук. Для анализа нужен без обработки:
  AGC, шумоподавление и эхоподавление искажают амплитуду.

## Продукт и инструменты

Unisono
: Название приложения; итал. «унисон». В сторах — «Unisono: Instrument Tuner».
  Обозначает точное совпадение высот, а не конкретный инструмент.

Инструмент → строй → струны
: Основная навигация приложения. Сначала выбирается инструмент (гитара, скрипка, домра…),
  затем его строй, затем настраивается струна. Хроматический режим — позиция в этом же списке.

Нониус
: Шкала прибора с двумя рядами рисок разной частоты. В интерфейсе — грубая шкала ±50 центов
  и тонкая ±5; ноль отмечен латунью.

Струны-унисоны
: Две или более струны с одинаковой целевой нотой (балалайка E4+E4, мандолина, 12-струнная
  гитара). Автоопределение обязано подсвечивать пару, а не выбирать одну случайно.

Контрабас
: Самый низкий смычковый инструмент оркестра; строй E1–A1–D2–G2, звучит на октаву ниже записи.
  Тюнер измеряет фактическую частоту.

Балалайка
: Русский трёхструнный щипковый инструмент. Прима: E4–E4–A4 (две унисонные струны).

Домра
: Русский щипковый инструмент. 3-струнная прима — квартовый строй E4–A4–D5;
  4-струнная — квинтовый G3–D4–A4–E5.

Мандолина
: 4 курса по две струны; строй G3–D4–A4–E5, как у скрипки. Настраивается как 4 струны.

Банджо
: 5-струнное (Open G: D3–G3–B3–D4–G4) и тенор (C3–G3–D4–A4). Пятая струна короче и
  крепится на грифе, но настраивается как обычная.

Адаптивное окно
: Размер окна анализа, выбираемый по нижней ноте строя: 4096 (≥82 Гц), 8192 (65–78 Гц),
  16384 (30–62 Гц). Чем ниже нота, тем длиннее окно и выше задержка.

## Rust и аудио

Crate
: Единица компиляции и пакет в Rust. В проекте четыре crate'а: `tuner-core`, `tuner-audio`,
  `tuner-storage`, `src-tauri`.

Workspace
: Набор crate'ов с общим `Cargo.lock` и профилями сборки; позволяет тестировать ядро
  отдельно от приложения.

Ownership / borrow checker
: Модель владения памятью в Rust: у значения один владелец, заимствования проверяются
  компилятором. Отсюда безопасность без сборщика мусора — и основной барьер входа в язык.

`unsafe`
: Блок, снимающий часть проверок компилятора (сырые указатели, FFI). В проекте допускается
  только в `tuner-audio` для вызовов oboe/AAudio.

`cpal`
: Крейт кроссплатформенного захвата и вывода звука; на macOS работает через CoreAudio.

`oboe`
: Официальные Rust-биндинги к Oboe (Android), который сам выбирает AAudio или OpenSL ES.
  Даёт `InputPreset`, `f32`-формат и низкую задержку.

AAudio / CoreAudio
: Низкоуровневые аудио-API Android и macOS соответственно. Через них приложение получает
  поток с микрофона.

`rtrb`
: Крейт lock-free SPSC-очереди (single producer / single consumer) для передачи `f32`-кадров
  из real-time колбэка в поток анализа без блокировок и аллокаций.

Real-time колбэк
: Функция, которую аудио-драйвер вызывает по прерыванию. В ней нельзя аллоцировать, блокироваться
  и логировать — иначе пропуски и щелчки.

`serde` / `serde_json`
: Фреймворк сериализации Rust и его JSON-формат; используется для `settings.json` и `presets.json`.

`criterion`
: Крейт бенчмарков; сравнивает реализации статистически и не даёт оптимизатору выбросить замер.

`hound`
: Крейт чтения и записи WAV; используется в тестах для фикстур.

`dhat`
: Профайлер кучи; в тестах подтверждает отсутствие аллокаций в горячем пути.

`uniffi`
: Генератор FFI-биндингов из Rust в Swift/Kotlin. Нужен только в плане Б — при переходе
  на нативные UI-оболочки.

WASAPI
: Аудио-API Windows; `cpal` использует его в shared mode, где система может ресемплить поток.

WebView2
: Chromium-движок, который Tauri использует на Windows. Обычно уже установлен в Windows 10/11.

WebKitGTK
: WebView для Linux; версия 4.1 нужна для Tauri 2. На NVIDIA возможен обход
  `WEBKIT_DISABLE_DMABUF_RENDERER=1`.

PipeWire / ALSA
: Звуковые подсистемы Linux. `cpal` работает через ALSA, PipeWire подхватывается плагином
  `pipewire-alsa`.

AppImage
: Самодостаточный исполняемый образ Linux-приложения; запускается после `chmod +x`.

SmartScreen
: Защита Windows, предупреждающая о неподписанных установщиках: «Подробнее» → «Выполнить всё равно».

NSIS / MSI
: Форматы установщиков Windows; NSIS выбран основным.

## Tauri и упаковка

Tauri 2
: Фреймворк десктопных и мобильных приложений: Rust-бэкенд и системный WebView для UI.
  Для проекта — одна оболочка на macOS и Android.

WebView
: Встроенный браузерный движок ОС (WKWebView на macOS, системный Chromium на Android),
  в котором отрисовывается Svelte-интерфейс.

IPC (Tauri)
: Канал связи UI с Rust: `invoke` для команд и `Channel<T>` для потока состояний.
  Сырое аудио через него не передаётся.

`tauri.conf.json`
: Конфигурация приложения: окно, идентификатор, формат бандла, entitlements, версия.

Capabilities
: Файлы разрешений Tauri: какие команды и API доступны UI. Ограничивают поверхность атаки
  WebView.

`src-tauri/gen/android`
: Сгенерированный Gradle-проект Android; здесь живут манифест, `MainActivity` и Kotlin-шим
  для разрешений и вибрации.

NDK (Android Native Development Kit)
: Набор инструментов для компиляции Rust под Android; без него `tauri android build` не работает.

Kotlin-шим
: Небольшой Kotlin-код в Android-проекте, который делает то, что Rust сделать не может:
  запрашивает `RECORD_AUDIO`, включает `FLAG_KEEP_SCREEN_ON`, вызывает вибрацию.

jpackage / JRE
: Инструмент упаковки Java-приложений и среда выполнения Java. В этом проекте **не используются** —
  упомянуты в ADR как причина отказа от JVM-стека.

DMG
: Образ диска для распространения macOS-приложений.

AAB
: Android App Bundle, формат публикации в Google Play; из него магазин собирает APK под устройство.

Notarization
: Проверка подписанного приложения Apple. Без неё Gatekeeper показывает предупреждение
  «не удалось проверить разработчика».

Gatekeeper
: Защитный механизм macOS, проверяющий подпись и notarization при первом запуске.

TCC
: Подсистема приватности macOS, выдающая доступ к микрофону, камере и т. п. Запрос появляется
  при первом обращении к устройству.
