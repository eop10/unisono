Unisono — технический проект
============================

**Версия:** 0.2 · 21.11.2026
**Статус:** решения зафиксированы, готов к разработке
**Аудитория:** разработчик(и) мобильного и desktop-приложения, QA, дизайнер

Документ описывает, как собрать **Unisono** — мультиинструментальный тюнер на **Rust** для
**macOS, Windows, Linux и Android**: гитара, бас, укулеле, скрипка, альт, виолончель, контрабас, балалайка,
домра, мандолина, банджо и хроматический режим, с настраиваемой опорной частотой A4.

.. note::

   Решения, которые не подтверждены заказчиком, помечаются **⚠️** и номером
   вопроса: **⚠️ Q13**. Все такие места собраны в разделе
   :ref:`sec-risks`.
