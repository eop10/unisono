# 2. Требования

## 2.1. Продукт в одном абзаце

**Unisono** — тюнер для струнных инструментов для macOS, Windows, Linux и Android: слушает микрофон, показывает ближайшую ноту,
измеренную частоту и отклонение в центах, и позволяет задать любую опорную частоту A4 вместо 440 Гц.
Работает с гитарой, бас-гитарой, укулеле, скрипкой, альтом, виолончелью, контрабасом, балалайкой,
домрой, мандолиной и банджо, а также в чистом хроматическом режиме без струн.
Один и тот же экран — на Android-смартфоне и в окне macOS, офлайн, без регистрации и сбора данных.

Ключевые особенности: **калибровка A4** (400–480 Гц с шагом 0,1) и **инструмент → строй → струны**
как основная навигация. Название в сторах — «Unisono: Instrument Tuner», bundle id — `app.unisono.tuner`.

## 2.4. User stories

**US-1. Настройка под оркестр (442 Гц).** Как скрипач, я хочу выставить 442 Гц, чтобы играть с оркестром.
*Приёмка:* ввод `442` с клавиатуры или выбор из списка; A4 = 442,0; целевые частоты струн пересчитаны;
значение сохранилось; индикатор 0 на настроенной струне.

**US-2. Другой инструмент.** Как преподаватель, я хочу переключиться со скрипки на виолончель.
*Приёмка:* в шторке выбираю «Виолончель» → список строёв меняется на один «Стандарт» (C2 G2 D3 A3);
чипы струн показывают 4 струны; целевая C2 = 65,4 Гц при 440; возврат к скрипке сохраняет её строй.

**US-3. Хроматический режим.** Как звукорежиссёр, я хочу проверить любую ноту без привязки к строю.
*Приёмка:* выбор «Хроматический» скрывает чипы струн; показывается ближайшая нота, октава и центы;
частота 440,0 показывает A4 и 0 центов; 466 Гц — A#4 и +? центов (проверяется расчётом).

**US-4. Унисон балалайки.** Как балалаечник, я хочу настроить пару одинаковых струн E4.
*Приёмка:* в строе «Прима» две струны E4; при автоопределении подсвечиваются обе; тап по любой
из них выбирает пару; переключение между E4 и A4 не «дребезжит».

**US-5. Свой строй.** Как домрист, я хочу сохранить нестандартный строй.
*Приёмка:* «Новый строй» доступен для домры; имя, 3 струны, ноты из сетки; после сохранения строй
появляется в списке домры и не виден у гитары.

**US-6. Язык.** Как англоязычный пользователь, я хочу интерфейс на английском.
*Приёмка:* переключение в настройках; все экраны, инструменты и строи переводятся; числа `82.4`,
`cents`; после перезапуска язык сохраняется.

**US-7. Шумная комната.** Как пользователь в классе, я не хочу ложных нот от разговоров.
*Приёмка:* при уровне ниже порога — «Слушаю…» без цифр; речь рядом не даёт нот.

**US-8. Отказ в доступе.** Как пользователь, случайно запретивший микрофон, я хочу понять, как исправить.
*Приёмка:* экран-объяснение и кнопка в системные настройки; после возврата доступ перепроверяется.

## 2.5. Use cases

### UC-1. Настроить скрипку в 442 Гц

1. Пользователь открывает приложение; по умолчанию — гитара, Standard E, 442 Гц (последний выбор).
2. Открывает шторку «Инструмент · Строй», выбирает «Скрипка».
3. Список строёв: «Стандарт» (G3 D4 A4 E5). Выбирает его.
4. Щипает/играет A4: через ≤ 120 мс видит `A4 · 442,0 Гц · +2 цента`.
5. Крутит колок; при |cents| ≤ 3 в течение 250 мс — «В строе», вибрация.

**Постусловие:** все четыре струны в допуске относительно 442 Гц.

### UC-2. Хроматическая проверка ноты

1. В шторке выбирает «Хроматический».
2. Струны скрыты; играет ноту.
3. Видит ближайшую ноту, октаву, частоту и центы; шкала работает так же.
4. Возвращается к инструменту — прежний строй восстановлен.

### UC-3. Пользовательский строй для домры

1. «Инструмент · Строй» → «Домра» → «3-струнная» → «Новый строй».
2. Вводит имя «Мой квартовый», 3 струны: E4, A4, D5.
3. Сохраняет; строй активен, целевые частоты пересчитаны от текущей A4.

### UC-4. Отказ в доступе к микрофону

1. Первый запуск → системный запрос → отказ.
2. Экран-объяснение, кнопка «Открыть настройки».
3. Возврат → проверка в `ON_RESUME` → автоматический старт.

## 2.6. Критерии приёмки MVP

- все MUST-требования реализованы и проверены по чек-листу 8.4;
- точность подтверждена автотестами на синтетике для каждой группы инструментов (гитара, скрипка,
  виолончель, бас/контрабас, балалайка) и ручной проверкой на реальных инструментах;
- сборки ставятся на чистое устройство: APK на Android 8 и Android 14 (sideload), Universal DMG
  на macOS 12+ (Apple Silicon и Intel), установщик на Windows 10/11, AppImage на Ubuntu 24.04;
  приложение запускается (на macOS — после «Всё равно открыть»), микрофон работает;
- переключение инструмента меняет список строёв и чипы струн без перезапуска захвата;
- хроматический режим не показывает струны ни в одном состоянии;
- `make html` документации собирается без предупреждений.
