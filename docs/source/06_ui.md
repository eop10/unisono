# 6. Интерфейс

## 6.1. Принципы

1. **Один экран — одно число.** Пользователь смотрит на инструмент, а не в телефон. Отклонение
   должно читаться боковым зрением на расстоянии 1 м.
2. **Инструмент → строй → струны.** Первое, что выбирают, — инструмент; строй и струны следуют из него.
   Хроматический режим стоит в том же списке и не требует отдельного переключателя.
3. **Цвет — не единственный носитель смысла.** Положение иглы, знак `+`/`−`, слова «ниже/выше/в строе»
   дублируют цвет (НФТ-11).
4. **Ничего не мигает.** Плавная интерполяция иглы; при `prefers-reduced-motion` анимации отключаются.
5. **Честность.** Если сигнала нет или он непериодический — приложение говорит об этом,
   а не показывает случайные цифры.

## 6.3. Экран «Тюнер»

### 6.3.1. Состав

| Элемент | Содержимое | Размер (mobile / desktop) | Поведение |
| --- | --- | --- | --- |
| Чип инструмента и строя | `Гитара · Standard E` | 16 / 14 px | тап → лист «Инструмент · Строй» |
| Чип A4 | `A4 442,0 Гц` | 14 / 13 px | тап → лист опорной частоты |
| Шестерёнка | иконка настроек (cog) | 30×30 px | тап → настройки |
| Буква ноты | `E`, `F#`, `До` | 200 / 142 px | приглушается в `Silent`/`Uncertain` |
| Октава | `2` | 24 / 18 px | научная нотация |
| Шкала-нониус | ±50 с подписями, тонкая ±5 | ширина контейнера | игла с инерцией, метки ±3 |
| Подписи краёв | `НИЖЕ` / `ВЫШЕ` | 8,5 px | часть SVG, переводятся |
| Число центов | `−7`, `+12`, `0` | 44 / 34 px | без ведущего нуля |
| Подпись | `центов` / `cents` | 9 px | скрывается в `Silent`/`Uncertain` |
| Измеренная частота | `82,4 Гц` | 18 / 16 px | `—`, если сигнала нет |
| Целевая частота | `82,4` | 10 px | серый, вторичный |
| Чипы струн | `E A D G B E` | 42×42 px | в хроматике скрыты |
| Индикатор уровня | 5 сегментов | 3×16 px | показывает вход |
| Статус | `НИЖЕ`/`ВЫШЕ`/`В СТРОЕ`/`СЛУШАЮ…` | 9,5 px | без числа, без дублирования |

Строка статуса **не повторяет** значение центов: число уже показано крупно. Это правило
появилось после ревью: `−07` в статусе читалось как «−0,7».

### 6.3.2. Шкала-нониус

- Грубая шкала ±50 центов, риски каждые 5, крупные каждые 25, подписи `−50`, `−25`, `0`, `+25`, `+50`.
- Тонкая шкала ±5, шаг 1 цент, риски только под базовой линией.
- Метки допуска ±3 — короткие латунные риски; ноль — латунная линия.
- Игла: 1,6 px, движется пружиной; в строе становится латунной.
- За пределами ±50 игла «прилипает» к краю, число продолжает расти.

### 6.3.3. Буква ноты

- Буква **не показывает направление**. Наклон и ширина не меняются — это было ошибкой раннего
  прототипа: ось `slnt` у Roboto Flex односторонняя, и «выше» молча теряло наклон.
- Вес меняется только как подтверждение: 560 в обычном состоянии, 720 при «в строе».
- В `Silent` буква заменяется коротким тире (54 px), в `Uncertain` — приглушается до 32 % opacity.
- `font-variation-settings` меняется на одном элементе; при `prefers-reduced-motion` переход
  отключается, остаётся мгновенная смена.

### 6.3.4. Поведение по состояниям

| Состояние | Буква | Шкала | Статус |
| --- | --- | --- | --- |
| `Silent` | `—` | пустая, иглы нет | «Слушаю…», серая точка |
| `Uncertain` | последняя, α = 0,32 | приглушена, игла на месте | «Играйте одну струну» (или удержание при затухании) |
| `Tracking` | актуальная | активная | «Ниже» / «Выше» / «Ровно» |
| `InTune` | актуальная, вес 720 | латунная игла на нуле | «В строе» + вибрация |
| `Error` | `—` | скрыта | текст ошибки + «Повторить» |
| `NoPermission` | `—` | скрыта | объяснение + «Открыть настройки» |

При естественном затухании струны показание удерживается в состоянии `Uncertain` (окно `hold_ms`, по умолчанию 1800 мс, #13) и отображается приглушённо (буква ноты с opacity 32 %, игла и центы остаются на месте), сглаживая переход в «Слушаю…» без резких миганий.

### 6.3.5. Хроматический режим

- Чип показывает «Хроматический»; чипы струн отсутствуют полностью.
- Нота — ближайшая к измеренной частоте по равномерной темперации; центы — от неё.
- Все остальные элементы (шкала, статус, настройки) работают так же.
- Возврат к инструменту восстанавливает последний выбранный строй.

### 6.3.6. Струны и унисоны

- Чипы показывают буквы без октав; активная — латунная с подчёркиванием.
- У балалайки две струны `E4`: при автоопределении подсвечиваются **обе**, тап по любой выбирает пару.
- У мандолины 4 курса: показываются 4 чипа, хотя физических струн 8.
- У банджо 5-струнного пятая струна (G4) — отдельный чип, несмотря на короткую мензуру.

## 6.4. Лист «Инструмент · Строй»

- Верхний блок — чипы инструментов: Гитара, Бас-гитара, Укулеле, Скрипка, Альт, Виолончель,
  Контрабас, Балалайка, Домра, Мандолина, Банджо, Хроматический. Активный — латунный.
- Нижний блок — строи выбранного инструмента: название, ноты, галочка; пользовательские
  помечены кнопкой «Изм.».
- «＋ Новый строй» доступен для всех инструментов, кроме хроматического; редактор подписывает
  инструмент: «Новый строй · Домра».
- Выбор инструмента не закрывает лист (кроме хроматического): пользователь сразу видит его строи.
- Выбор строя закрывает лист и применяет настройку.

## 6.5. Лист опорной частоты

- Крупное значение — **поле ввода** (tap → выделение, `inputmode="decimal"`), принимает `442`, `442,0`
  и `442.0`, по Enter/blur приводит к шагу 0,1 и границам 400–480.
- Слайдер 400–480 с шагом 0,1 синхронизирован с полем.
- Список частот с пояснениями: 415 барочная, 432 альтернативная, 435 старый концертный,
  438 пониженный концертный, 440 стандарт, 441 подстройка, 442 оркестровая, 443 высокий
  оркестровый, 466 высокий барочный.
- Кнопка «Готово» закрывает лист.

## 6.6. Настройки

| Секция | Пункты |
| --- | --- |
| Строй | Опорная частота A4; Инструменты и строи (текущий инструмент + переход к листу) |
| Отображение | Нотация (C-D-E / До-Ре-Ми), Тема, Крупный шрифт, **Язык (Русский / English)** |
| Точность | Допуск «в строе» (2/3/5), Чувствительность (низкая/обычная/высокая), Низкий диапазон |
| Вход (desktop-only) | Выбор аудиовхода («По умолчанию» или конкретное устройство CPAL; при недоступности — `(не найдено)` и мягкий фолбэк на дефолт; смена перезапускает захват, если он активен; на Android строка скрыта) |
| Обратная связь | Вибрация, Звук «в строе» |
| О приложении | версия, лицензии, приватность, «Сбросить настройки» |

Отдельного переключателя «Режим» нет: хроматический режим выбирается как инструмент,
а «Выбранная струна» — тапом по чипу. Это убрало дублирование настроек и путаницу.

## 6.8. Айдентика

### 6.8.1. Имя и позиционирование

- Бренд: **Unisono** (итал. «унисон»).
- Для будущих магазинов: **«Unisono: Instrument Tuner»** (25 символов).
- Для GitHub Releases: файлы `Unisono_<version>_aarch64.dmg` и `Unisono_<version>_x86_64.dmg`, подпись в «О программе» — `unsigned build`.
- Bundle id / package: `app.unisono.tuner`; display name — `Unisono`.
- Слово «Guitar» из названия и описаний **убрано**: продукт мультиинструментальный.

### 6.8.2. Знак

- Монограмма: жирная `U` (две струны) с латунной точкой в центре — «унисон», «в строе».
- Плита: тёмная `#0E0F10`, скругление 224/1024; `U` — `#E8E6E1`; точка — `#C8A15A`.
- Знак не привязан к гитаре: читается и для скрипки, и для балалайки.
- Проверен в 16, 24, 32, 64, 128, 256 px; на 16 px читается `U`, точка на грани — допускается
  увеличение точки на 10 % без потери формы.

### 6.8.3. Типографика и токены

| Роль | Шрифт / значение |
| --- | --- |
| Буква ноты | Roboto Flex, оси `wght` 460–720, `opsz` 144, `wdth` 100, `slnt` 0 |
| Цифры и подписи | JetBrains Mono, табличные цифры |
| Фон | `#0E0F10`; поверхность `#141618`; линии `#2A2D30` |
| Текст | `#E8E6E1`; вторичный `#8A8F94`; приглушённый `#5C6268` |
| Акцент | латунь `#C8A15A`; ошибка `#C4553B`; предупреждение `#C98A3B` |
| Светлая тема | бумага `#F3F0EA`, чернила `#14161A`, латунь `#8A6A2F` |

Зелёный в интерфейсе не используется: «в строе» — латунь + слово + форма иглы.

## 6.9. Доступность и локализация

- **Семантика.** Нота читается как «нота E, вторая октава»; центы — «минус семь центов, ниже»;
  шкала — `role="slider"` с `aria-valuemin=-50`, `aria-valuemax=50`, `aria-valuenow`.
- **Контраст.** ≥ 4,5:1 на обеих темах; проверка на солнце.
- **Размер.** Цифры масштабируются до 1,3×; шкала не меньше 96 px по высоте.
- **Движение.** `prefers-reduced-motion` отключает пружину иглы и смену веса буквы.
- **Язык.** RU/EN; числа с запятой/точкой; названия инструментов и строёв переводятся;
  нотация C-D-E / До-Ре-Ми независима от языка, но в EN солфеджио показывается латиницей
  (`Do Re Mi`).
