# 10. Риски, решения и открытые вопросы

## 10.1. Риски

| ID | Риск | Вероятность | Влияние | Меры |
| --- | --- | --- | --- | --- |
| R-1 | Низкий диапазон 30–65 Гц: окно 16384 даёт задержку ~340 мс и хуже держит атаку | Высокая | Среднее | адаптивное окно, допуск ±3 цента, тесты на B0/E1/C2, отдельная подсказка «играйте дольше» для баса и контрабаса |
| R-2 | Унисонные струны (балалайка E4+E4, мандолина) ломают автоопределение | Высокая | Среднее | подсветка пары, а не одной струны; тест «E4/E4/A4»; ручной выбор пары |
| R-3 | Android: NDK/oboe, разные прошивки, `InputPreset` | Высокая | Среднее | `VoiceRecognition`, фактическая `sample_rate`, тесты на 3 устройствах |
| R-4 | macOS: `cpal` теряет поток при смене устройства | Средняя | Среднее | перезапуск потока, `Silent`, резерв `AVAudioEngine` через `objc2` |
| R-5 | WebView: вид «как сайт», просадки fps на слабых Android | Средняя | Среднее | Canvas для шкалы, минимум перерисовок, профиль на 3 устройствах; план Б — нативные оболочки |
| R-6 | Аллокация/блокировка в real-time колбэке → щелчки | Средняя | Высокое | `rtrb`, запрет `Vec`/`Mutex`/`println!`, тест `rt_callback_no_alloc` |
| R-7 | Молодой мобильный тулинг Tauri ломается при обновлении | Средняя | Среднее | фиксированные версии, `src-tauri/gen/android` в репозитории, обновление отдельной задачей |
| R-8 | Имя: **Unison: Piano Tuner** (та же категория), TUNIC Unisono, `be.unisono.app`; марки не проверены | Высокая | Высокое | стор-название с дескриптором, package `app.unisono.tuner`, проверка марок в классах 9/15/41 до релиза |
| R-9 | Расползание объёма: 12 инструментов × строи × редактор | Средняя | Среднее | фиксированный список 5.5, данные отдельно от UI, кастомные строи только по одному шаблону |
| R-10 | Сроки: UI + инструменты + айдентика | Высокая | Высокое | этап UI 7 дней, буфер 2 дня, режем ФТ-16/ФТ-18 |
| R-11 | Нет нотаризации и стора: Gatekeeper и Play Protect пугают пользователей | Высокая | Среднее | ad-hoc подпись, SHA-256, блок «Первый запуск» с картинками, «О программе: unsigned build», позже — Developer ID |
| R-12 | Linux: ALSA/PipeWire и WebKitGTK ведут себя по-разному в дистрибутивах | Высокая | Среднее | Ubuntu 24.04 + Fedora 40 как целевые, AppImage, `WEBKIT_DISABLE_DMABUF_RENDERER=1`, список зависимостей в README |
| R-13 | Windows: SmartScreen и отсутствие WebView2 на старых сборках | Средняя | Среднее | NSIS + `webviewInstallMode`, инструкция «Выполнить всё равно», проверка на Win10/11 |

## 10.3. Открытые вопросы

**⚠️ Q6. Что входит в v1.1?**
По умолчанию: стробоскоп, экспорт/импорт строёв, iOS. Метроном и обучение — позже.
*Влияет:* 9.5.

**⚠️ Q8. Когда делаем iOS?**
По умолчанию: после стабилизации Android/macOS; `tuner-core` уже переносим.
*Влияет:* 9.5, план.

**⚠️ Q13. Юридическая проверка «Unisono» (марки, классы 9/15/41).**
По умолчанию: до публичного релиза. Найдены соседние имена: TUNIC Unisono, unisono social,
Unison: Piano Tuner, `be.unisono.app`. Публикация на GitHub без стора снижает риск,
но не отменяет его. *Блокер:* для маркетинга, не для кода.

**⚠️ Q15. Базовая версия Linux.**
По умолчанию: Ubuntu 24.04+ и Fedora 40+, AppImage + `.deb`; Snap/Flatpak не входят.
*Влияет:* CI, текст требований, поддержка.

**⚠️ Q14. Расширение списка инструментов (5-струнный контрабас, банджо-тенор Irish, домра-альт).**
По умолчанию: не входят; модель позволяет добавить без изменения кода UI.
*Влияет:* 5.5.

## 10.4. Допущения

| № | Допущение | Что изменится, если не так |
| --- | --- | --- |
| A-1 | Пользователь настраивает инструмент в тихом помещении, устройство ≤ 1 м | пороги `clarity`, подсказки, «шумный режим» |
| A-2 | Равномерная темперация достаточна | таблица интервалов на строй |
| A-3 | Все инструменты в концертном строе, транспонирование не нужно | коэффициент транспозиции в `Tuning` |
| A-4 | 6 струн — частный случай; 1–8 поддерживается моделью | ограничение редактора |
| A-5 | Пользователь принимает WebView-интерфейс | нативные оболочки, +2–3 недели |
| A-7 | Пользователь готов установить unsigned DMG и APK вручную | падение конверсии; нужен Developer ID / Play |
| A-6 | Приложение не монетизируется в MVP | биллинг, лицензии |
