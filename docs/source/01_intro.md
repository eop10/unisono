# 1. О документе

**Проект**
: **Unisono** — мультиинструментальный тюнер с настраиваемой опорной частотой для macOS, Windows, Linux и Android.

**Версия**
: 0.2 от 21.11.2026

**Статус**
: решения зафиксированы, документ готов к передаче в разработку

**Аудитория**
: разработка (Rust + Tauri, UI), QA, дизайн, продукт

## 1.1. Назначение

Документ описывает, как собрать Unisono: объём MVP, архитектуру, алгоритм определения высоты тона,
модель инструментов и строёв, интерфейс, айдентику, платформенные требования, сборку, тестирование
и выпуск. Материала достаточно, чтобы начать писать код без дополнительного анализа.

Ключевые особенности продукта:

- **опорная частота A4** 400–480 Гц с шагом 0,1: слайдер, список значений с пояснениями и ввод
  с клавиатуры;
- **инструмент → строй → струны**: гитара, бас-гитара, укулеле, скрипка, альт, виолончель,
  контрабас, балалайка, домра, мандолина, банджо;
- **хроматический режим** — та же шкала, но без струн и без привязки к строю;
- полностью офлайновая работа, без аккаунтов и телеметрии;
- единая визуальная система: нониус, латунный ноль, крупная буква ноты.

## 1.2. Границы

**Входит в документ:**

- функциональные и нефункциональные требования, user stories, use cases;
- архитектура Rust-ядра и Tauri-оболочки, поток данных от микрофона до индикатора;
- алгоритм NSDF/MPM, адаптивное окно анализа для диапазона 30–1400 Гц;
- модель данных: инструменты, строи, пользовательские строи, миграции;
- описание экранов, состояний, шкалы-нониуса и айдентики (знак, палитра, иконки);
- особенности Android (NDK, oboe, Kotlin-шим), macOS (ad-hoc подпись, Gatekeeper), Windows (WASAPI, WebView2) и Linux (ALSA, WebKitGTK);
- план работ, риски, принятые решения и открытые вопросы.

**Не входит:**

- маркетинговый план, ASO, монетизация;
- пиксельные макеты в Figma (описан состав экранов и токены);
- бэкенд — продукт полностью офлайновый;
- iOS/iPadOS (архитектура допускает, в план не входит — **⚠️ Q8**);
- фортепиано, духовые, ударные; только струнные щипковые и смычковые;
- табы, обучение на слух (кандидаты в v1.1+, **⚠️ Q6**);
- генератор эталонного тона — исключён из MVP (**⚠️ Q12**, 10.2).

## 1.5. Термины

Краткий словарь — в разделе {ref}`sec-glossary`. Три термина, без которых дальше читать неудобно:

- **Опорная частота (A4)** — частота ноты ля первой октавы, от которой строится вся сетка нот.
- **Цент** — сотая доля полутона: 1200 центов = октава. Отклонение «+10 центов» слышно, «±3» — уже строй.
- **Строй** — набор целевых нот струн инструмента (например, Standard E или DADGAD).
