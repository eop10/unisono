# Политика конфиденциальности Unisono

**Дата:** 21.11.2026

Unisono — офлайновый тюнер. Приложение не собирает, не передаёт и не хранит персональные данные.

## Что использует приложение

- **Микрофон.** Звук обрабатывается на устройстве в реальном времени, чтобы определить высоту тона.
  Аудио не записывается, не сохраняется и никуда не отправляется.
- **Локальные настройки.** Опорная частота, инструмент, строй, тема и язык хранятся в файлах
  приложения на устройстве (`settings.json`, `presets.json`). Пользователь может удалить их,
  очистив данные приложения.

## Чего приложение не делает

- не использует сеть и не имеет разрешения `INTERNET` на Android;
- не содержит аналитики, рекламы и сторонних SDK с телеметрией;
- не требует аккаунта, почты или номера телефона;
- не передаёт данные третьим лицам.

## Дети

Приложение не собирает данные и не предназначено для сбора данных о детях.

## Изменения

При изменении политики дата в начале документа обновляется вместе с релизом.
