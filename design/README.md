# Дизайн и прототип Unisono

Не участвует в сборке приложения. Здесь лежат материалы для UI и проверки решений.

- `prototype.html` — кликабельный прототип без логики;
- `index.html` — статичный макет (две платформы, два состояния);
- `mockup.png` — снимок макета;
- `fonts/` — Roboto Flex и JetBrains Mono (OFL), локально, без CDN.

## Как открыть

```bash
cd design
python3 -m http.server 8098
# http://127.0.0.1:8098/prototype.html
```

Шрифты подключены через `fonts.css`; при открытии двойным кликом (`file://`) часть браузеров
блокирует локальные woff2, поэтому нужен http-сервер.

## Что можно кликать

- чип инструмента → «Инструмент · Строй»: гитара, бас, укулеле, скрипка, альт, виолончель,
  контрабас, балалайка, домра, мандолина, банджо, хроматический;
- `A4` → опорная частота: число с клавиатуры, слайдер 400–480 и список с пояснениями;
- шестерёнка → настройки: нотация, тема, язык RU/EN, допуск, чувствительность, диапазон;
- чипы струн; «＋ Новый строй» → редактор.

## Прямые ссылки на состояния

`prototype.html#desktop&light&state=intune&lang=en`

| Параметр | Значения |
| --- | --- |
| `phone` / `desktop` | устройство |
| `dark` / `light` | тема |
| `state=` | `tracking`, `intune`, `silent`, `uncertain`, `noperm`, `error` |
| `cents=` | −50…50 |
| `instrument=` | id инструмента, например `violin` |
| `tuning=` | id строя, например `drop_d` |
| `overlay=` | `presets`, `reference`, `settings`, `editor` |
| `lang=` | `ru`, `en` |
| `instant` | отключить анимации (для скриншотов) |
